About PoultryDetect

PoultryDetect is a web application that uses deep learning and image classification to help users identify possible poultry diseases from uploaded images. The project combines a trained machine learning model with a Flask-based website to make image-based predictions accessible through a simple interface.

🤖

AI & Deep Learning

The application uses a trained deep learning model to classify poultry images into supported categories: Coccidiosis, Healthy, Newcastle Disease, and Salmonella.

🖼️

Image-Based Prediction

Users can upload an image or capture one using the camera interface. The application processes the image and displays the model's predicted class.

💻

Simple Web Interface

Built with Flask, HTML, CSS, and Python, PoultryDetect connects the prediction model with a user-friendly website for easy interaction.

Important: PoultryDetect provides AI-generated image classifications for informational purposes only. Its predictions are not a confirmed veterinary diagnosis. Consult a qualified veterinarian before making treatment decisions.
